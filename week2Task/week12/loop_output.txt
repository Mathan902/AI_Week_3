Read the signing secret with `os.environ` (the env var name `ACME_WEBHOOK_SIGNING_SECRET` is my choice, not from the docs), then pass the raw request body and the `X-Acme-Signature` header to `verify_signature` in `acme.webhooks`. The v3 docs show this call but don't document what `verify_signature` does on a bad signature, so check that before relying on it.

```python
import os
from acme.webhooks import verify_signature

WEBHOOK_SIGNING_SECRET = os.environ["ACME_WEBHOOK_SIGNING_SECRET"]

def handle_webhook(raw_body: bytes, headers) -> None:
    verify_signature(
        payload=raw_body,
        signature_header=headers["X-Acme-Signature"],
        secret=WEBHOOK_SIGNING_SECRET,
    )
```
